## `01` — ABOUT THE PROJECT

**Taco Clicker** is a retro-inspired clicker game built around a simple idea: click your way toward a growing taco empire.

Featuring a nostalgic terminal-inspired aesthetic, this project explores the fundamentals of web development through an interactive and playful experience.

## `02` — FEATURES

- 🌮 Taco-themed clicker gameplay
- 🖥️ Retro-inspired user interface
- 🎨 Custom CSS styling
- 🔤 Pixel-inspired typography
- ⚡ Interactive elements powered by JavaScript

*Features listed here should reflect the final, tested version of the game.*

## `04` — GETTING STARTED

### Requirements

- A modern web browser
- An internet connection to load the external styles and fonts

### Run locally

1. Clone or download this repository.
2. Open `taco.html` in your browser.
3. Start clicking and enjoy the tacos!

No build process is required for the current standalone HTML version.
